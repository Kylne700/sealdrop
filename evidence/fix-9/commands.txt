Fix stage 9 (QA R5's R5-L1 and R5-I2): how the files in this folder were made. <repo> is the sealdrop checkout; /tmp/fq-F9 is a scratch directory.
Before = dd76bcd (fix stage 8 and the Settings spacing, live). After = 26957f6 (the fix commit of this stage; the evidence commit after it changes no source).
Every browser job is headless Chromium (puppeteer-core with /usr/bin/chromium, or Playwright 1.64.1 Chromium for copybtn.mjs) on the mock Arkiv (window.__MOCK, no
network, no key material), run with `env -u DISPLAY nice -n 10`, one browser at a time. No live RPC run at all. The extras and the row probes freeze the page's Date (2026-10-17 09:30 UTC);
copybtn.mjs uses real time, because it measures the 1.8 s reset.

Setup
  git clone <repo> /tmp/fq-F9/base   (dd76bcd);  ln -s <repo>/.env.local /tmp/fq-F9/base/.env.local;  (cd /tmp/fq-F9/base && npm ci --prefer-offline --no-audit)
  git clone <repo> /tmp/fq-F9/after  (26957f6);  .env.local linked the same way; node_modules linked to base's (package-lock.json is identical: cmp)
  cp <repo>/evidence/final-qa/R3/scripts/screens/* /tmp/fq-F9/harness/ ; chmod +x build-mock-r2.sh screens-r2.sh there (the originals have no exec bit and screens-r2.sh calls the build script directly)
  mock for R5-L1:   bash /tmp/fq-F9/harness/build-mock-r2.sh /tmp/fq-F9/<base|after> <repo>/evidence/final-qa/R5/scripts/mock-arkiv-r5.ts /tmp/fq-F9/dist-<base|after>-r5
                    (R5's mock answers a sweep from the state at the moment the query arrives and then delays it, so a tip that lands during the delay is not in the answer)
  mock for the rest: the R2 mock (mock-arkiv-r2.ts) built from each clone: before = /tmp/fq-F9/screens-base/dist (made by screens-r2.sh); after = /tmp/fq-F9/dist-after-r2
                     (build-mock-r2.sh on the after clone; diff -rq shows it identical to the dist/ that the after screens run builds)
